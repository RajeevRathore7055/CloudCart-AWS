VirtualBox

A desktop hypervisor (type 2). Physical machine → host OS → VirtualBox → guest virtual machines.

Link to CloudCart: a student can run the app in a VirtualBox VM to learn what EC2 does at large scale. EC2 uses a type 1 hypervisor close to the hardware.

Google App Engine

A PaaS: upload your code and Google runs, scales and patches it. No servers to manage.

Contrast: on EC2 (IaaS) we install and run Nginx, Gunicorn and updates ourselves.

OpenStack

Open-source software to build a private or hybrid IaaS cloud (compute: Nova, storage: Swift/Cinder, network: Neutron).

Contrast: EC2, S3 and VPC are AWS's proprietary counterparts of Nova, Swift and Neutron.

Hadoop & MapReduce

Hadoop stores big data across many machines (HDFS) and processes it in parallel with MapReduce.

Open the MapReduce simulation →

Cloud Federation
Cloud A Federation layer (trust, identity, APIs) Cloud B

Cloud federation lets separate providers share resources and services. If Cloud A is overloaded it can use capacity from Cloud B, with common identity, security and billing rules. CloudCart runs on one cloud (AWS) and does not implement federation; this diagram is for explanation.
